# excel-data-visualization
Excel Dashboard analyzing VogueNest Store's sales, orders, and customer trends. Women lead (72%), Amazon dominates (100%), Maharashtra tops ($0.80M). Built with Excel &amp; Power Query for deep insights
## 📂 Project Files  
- **VogueNest_Dashboard.xlsx** – Interactive Excel dashboard with sales analysis.  
- **Raw_Data.csv** – Original dataset used for analysis.  
- **Insights.pdf** – Summary of key findings and trends.  

## 🛠 Tools & Technologies  
- **Microsoft Excel** – Data cleaning, Pivot Tables, Charts.  
- **Power Query** – Data transformation and automation.  
- **Data Visualization** – Bar Charts, Pie Charts, Trend Analysis.  

## 📊 Key Insights  
- **Women dominate sales (72%)**, **Amazon leads orders (100%)**, **Maharashtra tops revenue ($0.80M)**.  
- Interactive filters for category, sales channel, and month-wise analysis.  

## 🚀 How to Use  
1. Open **VogueNest_Dashboard.xlsx** in Microsoft Excel.  
2. Use slicers to filter sales trends dynamically.  
3. Analyze insights from charts and pivot tables.
